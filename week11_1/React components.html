Cheat sheet The key patterns from the study guide in one place.

Functional component

function MyComp() {
  return <div>Hello</div>;
}

Props (destructured)

function Hi({ name, age = 0 }) {
  return <p>{name}, {age}</p>;
}

Render a list

{items.map(item => (
  <li key={item.id}>
    {item.name}
  </li>
))}

Ternary

{isOn
  ? <p>On</p>
  : <p>Off</p>
}

Short-circuit &&

{isAdmin &&
  <button>Delete</button>
}

props.children

function Panel({ children }) {
  return <div>{children}</div>;
}

JSX rules

one root element (or <></>)
className, not class
self-close: <br />
JavaScript in {expressions}

The key rule

key={item.id}  // stable id: good
key={index}    // avoid

How this page is built One file, no build step.

React is loaded from a CDN. Each exercise's source is written once, inside this page. The page shows it in the code box, compiles it in the browser and mounts it in the output, so the code you read is the code that runs. The homework projects above are full apps with a build tool.
